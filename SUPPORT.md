# Getting help

1. **Read the docs**: start with the [README](README.md), then
   [installation](docs/installation.md) and [troubleshooting](docs/troubleshooting.md).
2. **Check `jtrac status` and `jtrac logs`**: most problems explain themselves there.
3. **Search existing issues**: https://github.com/Jerophin123/JTrac/issues
4. **Open an issue** with the bug template (version, platform, steps, logs without personal data).

Security problems: [SECURITY.md](SECURITY.md). There is no paid support; help is given by the
community on a best-effort basis.
